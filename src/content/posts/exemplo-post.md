Este texto é **conteúdo puro**. Para publicar um post novo, basta criar
outro arquivo `.md` aqui dentro seguindo o mesmo formato (front-matter +
texto). Nenhuma edição de HTML, CSS ou componentes é necessária.

Isso significa que você pode:
- Escrever o post você mesmo, direto neste arquivo
- Pedir pra uma IA gerar o rascunho e só colar aqui
- Ou automatizar a criação desse arquivo por outro processo

O pipeline (GitHub Actions) cuida de transformar isso em uma página HTML
publicada automaticamente a cada commit.
